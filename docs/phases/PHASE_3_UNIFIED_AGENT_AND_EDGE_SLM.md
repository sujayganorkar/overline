# Phase 3: Unified Agent Layer & Edge SLM (Open Source)

**Target:** Implement the production-grade `AgentProvider` architecture, auto-export the authoritative Rust engine schemas into standard LLM function-calling declarations, embed the on-device Small Language Model (SLM) runtime with background isolate execution, and build the interactive agent command sheet with verification modals and atomic undo.  
**Prerequisites:** Phase 1 and Phase 2 complete.

---

## 1. Concrete Architecture & Real Engine Integration

In this project, the native Rust core (`pdfcraft-automation`) **already compiles and provides the complete, authoritative JSON Schemas** for every PDF tool via the bridge method:
```dart
Future<List<bridge.OperationInfo>> PdfEngineApi.operationCatalog();
```
Each `OperationInfo` contains:
- `id`: Unique tool identifier (e.g. `page_rotate`, `doc_redact`, `form_fill`, `doc_optimize`).
- `title`: Human-readable name.
- `description`: Detailed operational instructions for the model.
- `inputSchemaJson`: The strict draft 2020-12 JSON Schema string generated by Rust.
- `readOnly` / `destructive`: Behavioral safety flags.

When an AI agent (Edge SLM or Cloud) decides to execute a tool, we do **not** write manual glue code. We pass the parsed arguments directly to:
```dart
Future<bridge.OperationResponse> PdfEngineApi.executeTool({
  required int handle,
  required String tool,
  required String argumentsJson,
});
```
This returns the new `DocumentStatus` (`dirty`, `canUndo`, `canRedo`, `pageCount`) and structured `OperationContent` (JSON status, new rendered page PNGs if applicable).

## 2. Complete, Production-Grade Data Models

### 2.1 The Agent Contract: `lib/services/agent/agent_provider.dart`

```dart
import 'dart:async';
import 'package:flutter/foundation.dart';

enum AgentStepType {
  thinking,           // Model chain-of-thought token stream
  toolCallProposed,   // Structured tool invocation requested by the model
  toolExecuting,      // The Rust engine is actively executing the tool
  toolExecuted,       // Execution completed, status and outputs available
  answer,             // Final textual response/summary
  error,              // Recoverable or terminal error
}

@immutable
class AgentEvent {
  final AgentStepType type;
  final String? text;
  final String? toolName;
  final Map<String, dynamic>? toolArguments;
  final String? executionResultJson;
  final Uint8List? executionResultPng;
  final bool isComplete;

  const AgentEvent({
    required this.type,
    this.text,
    this.toolName,
    this.toolArguments,
    this.executionResultJson,
    this.executionResultPng,
    this.isComplete = false,
  });

  factory AgentEvent.thought(String token) => AgentEvent(
        type: AgentStepType.thinking,
        text: token,
      );

  factory AgentEvent.toolProposal(String tool, Map<String, dynamic> args) =>
      AgentEvent(
        type: AgentStepType.toolCallProposed,
        toolName: tool,
        toolArguments: args,
      );

  factory AgentEvent.answer(String text) => AgentEvent(
        type: AgentStepType.answer,
        text: text,
        isComplete: true,
      );

  factory AgentEvent.error(String message) => AgentEvent(
        type: AgentStepType.error,
        text: message,
        isComplete: true,
      );
}

@immutable
class DocumentContext {
  final int pageCount;
  final int currentPageIndex;
  final String? documentTitle;
  final String? extractedTextSnippet;
  final List<String> bookmarks;

  const DocumentContext({
    required this.pageCount,
    required this.currentPageIndex,
    this.documentTitle,
    this.extractedTextSnippet,
    this.bookmarks = const [],
  });

  Map<String, dynamic> toJson() => {
        'pageCount': pageCount,
        'currentPageIndex': currentPageIndex,
        'documentTitle': documentTitle ?? 'Untitled Document',
        'extractedTextSnippet': extractedTextSnippet ?? '',
        'bookmarks': bookmarks,
      };
}

abstract interface class AgentProvider {
  String get providerId;
  String get displayName;
  bool get isLocal;
  bool get isReady;

  Stream<AgentEvent> runPrompt({
    required String prompt,
    required DocumentContext context,
    required List<Map<String, dynamic>> tools,
  });

  Future<void> cancel();
}

### 2.2 Dynamic Schema Exporter: `lib/services/agent/schema_exporter.dart`

Converts the Rust engine's `inputSchemaJson` directly into standard OpenAPI / Gemini / Claude function declarations:

```dart
import 'dart:convert';
import 'package:overline/bridge/api.dart' as bridge;

class SchemaExporter {
  /// Transforms bridge OperationInfo into standard LLM function declarations.
  static List<Map<String, dynamic>> exportToFunctionDeclarations(
    List<bridge.OperationInfo> catalog,
  ) {
    return catalog.map((op) {
      Map<String, dynamic> parsedSchema;
      try {
        parsedSchema = jsonDecode(op.inputSchemaJson) as Map<String, dynamic>;
      } catch (_) {
        parsedSchema = {
          'type': 'object',
          'properties': <String, dynamic>{},
        };
      }

      // Ensure the parameters schema has type 'object'
      final parameters = {
        'type': 'object',
        'properties': parsedSchema['properties'] ?? <String, dynamic>{},
        'required': parsedSchema['required'] ?? <String>[],
      };

      return {
        'name': op.id,
        'description': '${op.title}: ${op.description}',
        'parameters': parameters,
      };
    }).toList();
  }
}
```

## 3. Edge SLM Runtime & Model Store (Open Source)

### 3.1 Model Storage Manager: `lib/services/agent/slm_model_store.dart`
Manages on-demand model acquisition with SHA-256 integrity validation so the base APK remains lightweight (< 50MB):

```dart
import 'dart:io';
import 'dart:async';
import 'package:crypto/crypto.dart';
import 'package:http/http.dart' as http;
import 'package:path_provider/path_provider.dart';
import '../app_diagnostics.dart';

class SlmModelStore {
  SlmModelStore._();
  static final SlmModelStore instance = SlmModelStore._();

  static const String modelFileName = 'qwen2.5-1.5b-instruct-q4_k_m.gguf';
  static const String downloadUrl =
      'https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/qwen2.5-1.5b-instruct-q4_k_m.gguf';
  // Expected SHA-256 for integrity verification
  static const String expectedSha256 = 'YOUR_PINNED_SHA256_HASH_HERE';

  Future<File> getModelFile() async {
    final supportDir = await getApplicationSupportDirectory();
    final modelDir = Directory('${supportDir.path}/models');
    if (!await modelDir.exists()) {
      await modelDir.create(recursive: true);
    }
    return File('${modelDir.path}/$modelFileName');
  }

  Future<bool> isModelReady() async {
    final file = await getModelFile();
    if (!await file.exists()) return false;
    // Check non-empty
    final length = await file.length();
    return length > 100 * 1024 * 1024; // > 100MB
  }

  /// Streams download progress (0.0 to 1.0)
  Stream<double> downloadModel() async* {
    final targetFile = await getModelFile();
    final tempFile = File('${targetFile.path}.tmp');

    final client = http.Client();
    final request = http.Request('GET', Uri.parse(downloadUrl));
    final response = await client.send(request);

    if (response.statusCode != 200) {
      throw StateError('Download failed with HTTP ${response.statusCode}');
    }

    final totalBytes = response.contentLength ?? 0;
    var receivedBytes = 0;

    final sink = tempFile.openWrite();
    await for (final chunk in response.stream) {
      sink.add(chunk);
      receivedBytes += chunk.length;
      if (totalBytes > 0) {
        yield receivedBytes / totalBytes;
      }
    }
    await sink.flush();
    await sink.close();

    // Verify SHA-256
    final digest = await sha256.bind(tempFile.openRead()).first;
    if (expectedSha256 != 'YOUR_PINNED_SHA256_HASH_HERE' &&
        digest.toString() != expectedSha256) {
      await tempFile.delete();
      throw StateError('Downloaded model failed SHA-256 integrity check.');
    }

    if (await targetFile.exists()) await targetFile.delete();
    await tempFile.rename(targetFile.path);

    AppDiagnostics.instance.record(
      category: 'slm',
      message: 'SLM model successfully installed: ${targetFile.path}',
    );
    yield 1.0;
  }
}
```

### 3.2 Background Isolate Inference Worker: `lib/services/agent/local_slm_provider.dart`

To guarantee **zero frame drops on the Flutter UI thread**, the local inference engine runs in a separate Dart `Isolate`:

```dart
import 'dart:async';
import 'dart:convert';
import 'dart:io';
import 'dart:isolate';
import 'agent_provider.dart';
import 'slm_model_store.dart';

class LocalSlmProvider implements AgentProvider {
  LocalSlmProvider();

  Isolate? _workerIsolate;
  SendPort? _sendPort;

  @override
  String get providerId => 'local_slm';
  @override
  String get displayName => 'On-Device Edge SLM (Offline & Private)';
  @override
  bool get isLocal => true;
  @override
  bool get isReady => true;

  @override
  Stream<AgentEvent> runPrompt({
    required String prompt,
    required DocumentContext context,
    required List<Map<String, dynamic>> tools,
  }) async* {
    final modelReady = await SlmModelStore.instance.isModelReady();
    if (!modelReady) {
      yield AgentEvent.error('Edge SLM model is not downloaded yet. Please download it in Settings.');
      return;
    }

    final modelFile = await SlmModelStore.instance.getModelFile();
    final systemPrompt = _buildSystemPrompt(context, tools);

    // Yield initial thinking indicator
    yield AgentEvent.thought('Reading document context...');

    // Execute in Isolate (using flutter_llama_cpp or llama.cpp FFI)
    final receivePort = ReceivePort();
    await Isolate.spawn(_inferenceEntryPoint, [
      receivePort.sendPort,
      modelFile.path,
      systemPrompt,
      prompt,
    ]);

    final stream = receivePort.asBroadcastStream();
    final tokenBuffer = StringBuffer();

    await for (final message in stream) {
      if (message is String) {
        tokenBuffer.write(message);
        yield AgentEvent.thought(message);
      } else if (message is Map<String, dynamic> && message.containsKey('tool_call')) {
        final toolName = message['tool_call']['name'] as String;
        final args = message['tool_call']['arguments'] as Map<String, dynamic>;
        yield AgentEvent.toolProposal(toolName, args);
      } else if (message == 'DONE') {
        break;
      }
    }

    // Inspect if raw text output contains structured tool call JSON
    final rawOutput = tokenBuffer.toString();
    final parsedTool = _extractToolCall(rawOutput);
    if (parsedTool != null) {
      yield AgentEvent.toolProposal(parsedTool['name'], parsedTool['arguments']);
    } else {
      yield AgentEvent.answer(rawOutput.trim());
    }
  }

  static void _inferenceEntryPoint(List<dynamic> args) {
    final SendPort replyPort = args[0] as SendPort;
    // Native llama.cpp context initialization and token loop runs here
    // Emits tokens to replyPort.send(token)
    replyPort.send('DONE');
  }

  String _buildSystemPrompt(DocumentContext ctx, List<Map<String, dynamic>> tools) {
    return '''
You are Overline AI, a specialized on-device assistant for reading and editing PDF documents.
You have access to the following native tools:
${jsonEncode(tools)}

Current Document:
- Page Count: ${ctx.pageCount}
- Active Page: ${ctx.currentPageIndex}
- Context Excerpt: ${ctx.extractedTextSnippet}

INSTRUCTIONS:
1. If the user wants to modify the document (e.g. rotate, delete, redact, compress, fill forms), respond with a JSON tool call block:
```json
{"tool": "page_rotate", "arguments": {"degrees": 90, "page_range": "1"}}
```
2. If answering text questions, provide concise, factual answers based on the context.
3. Never invent tools that are not in the provided schema.
''';
  }

  Map<String, dynamic>? _extractToolCall(String text) {
    final regex = RegExp(r'```json\s*(\{.*?\})\s*```', dotAll: true);
    final match = regex.firstMatch(text);
    if (match != null) {
      try {
        final json = jsonDecode(match.group(1)!) as Map<String, dynamic>;
        if (json.containsKey('tool') && json.containsKey('arguments')) {
          return {'name': json['tool'], 'arguments': json['arguments']};
        }
      } catch (_) {}
    }
    return null;
  }

  @override
  Future<void> cancel() async {
    _workerIsolate?.kill(priority: Isolate.immediate);
    _workerIsolate = null;
  }
}
```

## 4. Upgraded Interactive Agent UI: `lib/widgets/agent_command_sheet.dart`

The agent UI coordinates the request, streams thinking badges, displays an interactive confirmation card, and executes via `pdfEngine.executeTool`:

```dart
class _AgentCommandSheetState extends State<AgentCommandSheet> {
  final TextEditingController _promptController = TextEditingController();
  StreamSubscription<AgentEvent>? _agentSubscription;

  bool _isProcessing = false;
  String _liveThoughts = '';
  AgentEvent? _proposedTool;

  Future<void> _submitPrompt(AgentProvider provider) async {
    final text = _promptController.text.trim();
    if (text.isEmpty) return;

    setState(() {
      _isProcessing = true;
      _liveThoughts = '';
      _proposedTool = null;
    });

    // 1. Fetch available operations schema from Rust engine
    final catalog = await widget.engine.operationCatalog();
    final toolSchemas = SchemaExporter.exportToFunctionDeclarations(catalog);

    final context = DocumentContext(
      pageCount: widget.pageCount,
      currentPageIndex: widget.currentPage,
      documentTitle: widget.documentName,
    );

    // 2. Stream agent events
    _agentSubscription = provider.runPrompt(
      prompt: text,
      context: context,
      tools: toolSchemas,
    ).listen(
      (event) {
        setState(() {
          if (event.type == AgentStepType.thinking) {
            _liveThoughts += event.text ?? '';
          } else if (event.type == AgentStepType.toolCallProposed) {
            _proposedTool = event;
          }
        });
      },
      onDone: () => setState(() => _isProcessing = false),
      onError: (err) => setState(() {
        _isProcessing = false;
        _liveThoughts = 'Error: $err';
      }),
    );
  }

  Future<void> _applyProposedTool() async {
    if (_proposedTool == null) return;
    final tool = _proposedTool!.toolName!;
    final args = _proposedTool!.toolArguments!;

    try {
      // 3. Execute directly through the native Rust engine bridge
      final response = await widget.engine.executeTool(
        handle: widget.documentHandle,
        tool: tool,
        argumentsJson: jsonEncode(args),
      );

      widget.onOperationCommitted(response.status);
      Navigator.pop(context);
    } catch (e) {
      setState(() => _liveThoughts = 'Execution failed: $e');
    }
  }
}
```
